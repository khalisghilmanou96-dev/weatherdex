# WeatherDex 🌤️

Site météo mondial statique, prêt pour GitHub Pages.

## Fonctionnalités
- Recherche de villes dans le monde
- Météo actuelle
- Température et ressenti
- Humidité et vent
- Probabilité de précipitations
- Lever / coucher du soleil
- Prévisions sur 7 jours
- Celsius / Fahrenheit
- Géolocalisation navigateur
- Villes populaires

## API
Données météo et géocodage : Open-Meteo.
https://open-meteo.com/

Aucune clé API n'est nécessaire pour l'utilisation standard de cette démo.
